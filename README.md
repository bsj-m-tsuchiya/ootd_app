# Kiroku

「今季買った服」と「買う予定の服」だけをかわいく残す購入品ログアプリです。
Next.js 15 + Prisma + PostgreSQL で動きます（ルート直下の `index.html` などは初期の静的モックです）。

## 開き方

DockerでNext.jsとPostgreSQLを起動します。

```bash
docker compose up --build
```

アプリは `http://localhost:3000` で開きます。

DBの中身を見るときは、別ターミナルでPrisma Studioを起動します。

```bash
docker compose exec web npm run prisma:studio
```

Prisma Studioは `http://localhost:5555` で開きます。

## 構成

- `src/app/page.tsx` — 状態管理とAPI呼び出しのオーケストレーション
- `src/components/` — 画面ごとのコンポーネント（登録 / 買う / まとめ / 詳細 / ナビ / トースト）
- `src/lib/` — 型・整形ヘルパー・まとめ画像のcanvas書き出し
- `src/app/api/items/` — Prisma経由のCRUD API

## デザイン

- フォントは `next/font` で Cormorant Garamond（欧文見出し）+ しっぽり明朝（和文見出し）+ Zen角ゴシックNew（本文）を読み込み。
- 配色は生成り（`#fbf7f1`）ベースにテラコッタ（`#b3654a`）をアクセントにした雑誌風トーン。
- 画面遷移・まとめグリッド・詳細シート・トーストにさりげないアニメーション（`prefers-reduced-motion` 対応）。

## 今回の設計メモ

- 登録はクイック登録が基本。写真のアップロード / スクショの貼り付け / URLからの自動入力（OGP取得）に対応し、詳細項目は「詳しく書く」で開きます。
- アップロード画像は `/api/upload` 経由で `public/uploads/` に保存されます（gitignore済み）。
- 購入品まとめには追加ボタンを置かず、スクショしやすいビジュアル一覧にしています。
- 購入品まとめはシーズン名をタップ（または長押し）すると、その位置のままホイールのように切り替えられます。ホイールはドラッグやスクロールでも回せます。
- 「画像にする」ボタンで投稿用画像の実寸プレビューを表示し、そこでサイズ（IG 1:1 / IG 4:5 / X 16:9）、文字あり・なし、@アカウント名を調整してから保存します。
- 保存画像はクリーム地に白マットのコラージュ風。シーズンの英字見出し＋ハッシュタグ＋点数・合計金額＋@アカウント名が入ります。
- 王冠ボタンで「購入品枠」と「ベストバイ枠」を切り替え。ベストバイ枠は詳細画面で王冠を付けた服だけが並ぶ選抜制です。
- 買うもの画面は TODAY / THIS WEEK / UPCOMING / SOMEDAY / RELEASED にセクション分けされ、カードにカウントダウンを表示します。
- 発売済みの買うものは「購入品にする」ワンタップでまとめへ移動します。
- 詳細画面は見る場所にして、編集ボタンからだけ項目を変更できます。Escキーや上部バーの下スワイプでも閉じられます。
- 削除は確認ダイアログの代わりに「元に戻す」付きトーストで取り消せます。
- 操作結果（記録・保存・移動・削除・エラー）はトーストで通知します。
- PWA対応（manifest + アイコン）。スマホのホーム画面に追加できます。共有シートからの受け取りは未対応です。
