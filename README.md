# Kiroku Mock

「今季買った服」と「買う予定の服」だけを記録するアプリの静的モックです。

## 開き方

DockerでNext.jsとPostgreSQLを起動します。

```bash
docker compose up --build
```

アプリは `http://localhost:3000` で開きます。

DBの中身を見るときは、別ターミナルでPrisma Studioを起動します。

```bash
docker compose exec web npm run prisma:studio
```

Prisma Studioは `http://localhost:5555` で開きます。

## 今回の設計メモ

- 購入品まとめには追加ボタンを置かず、スクショしやすい白背景のビジュアル一覧にしています。
- 購入品まとめはシーズン名を長押しすると、その位置のままホイールのように切り替えられます。
- まとめ画面は下ナビを自動で隠し、右上の保存ボタンで `1200x1600` の投稿用画像を生成します。
- まとめ画面では初回表示時とスクショ系キー操作時に、投稿用画像の作成導線を表示します。
- 買うもの画面ではシーズンを控えめな分類ラベル、購入予定日時を予定として強調し、下部に画像つきのリリースタイムラインを置いています。
- 詳細画面は見る場所にして、編集ボタンからだけ項目を変更できます。
- 買うもののリマインドは詳細の編集モードから変更できます。
- 買った服も詳細の編集モードからブランド、商品名、サイズ、値段、シーズン、メモを変更できます。
- 買うものを購入品まとめへ移す演出は保留中です。
- 登録画面では画像だけでも保存でき、ブランド、商品名、サイズ、値段、URLはあとで埋める前提にしています。
- 購入品まとめにはSNSアカウント名を表示でき、保存画像にも反映されます。
